# オイコム — Codexデモ実装用企画書 v1.0

作成日：2026-10-27 / 対象：日本語・スマートフォン／PC / 状態：実装前の仕様セット

**サッカー開催日の、駅の混雑に備えるカレンダー。**
「追い込む」と「おい！混む！」を掛けた名称。日付と駅・地域から、近くで開催される試合と来場・帰宅の注意時間帯を確認する。

このZIPは完成アプリではなく、Codexに渡す企画・画面・データ・実装指示のセットです。

## 現在の実装

[公開版のオイコム](https://tetoriapot.github.io/oikomu/)をGitHub Pagesで公開しています。デモ版・実験公開中です。右上に更新情報・ライト／ダーク切替・Helpを設け、日本時間の毎日0:00に日程の取得を開始します。取得時点のデータと出典・確認日時を履歴に保存します。詳しくは[実験公開と日次更新](docs/10_PUBLIC_RELEASE.md)を参照してください。

2026-10-29に`app/`へ動作するアプリを実装し、追加依頼により2026/27 J1の実データに対応しました。20クラブ・380試合・22会場・39駅を収録しています。起動・更新方法は[アプリのREADME](app/README.md)、追加仕様は[実データ仕様](docs/08_REAL_DATA.md)を参照してください。以下は元のデモ企画書です。デモは`?data=demo`で引き続き使用できます。

## 使い方

1. ZIPを展開し、フォルダー全体をCodexの作業対象にする。
2. `CODEX_START.md` の本文を最初の依頼として貼る。
3. Codexに `TASKS.md` のPhase 0〜5まで実装してもらう。
4. 実装後、Codexが作るアプリのREADMEに従って起動する。

ブラウザーで読みたい場合は `OIKOMU_DEMO_PLAN.html` を開く。画面の見た目は `design/screen_reference.html` を参照。どちらも説明用資料であり、検索できるアプリではない。

## この版で作るもの

- 関東5スタジアム・7駅、2026年11〜12月の架空の試合24件。
- 日付＋駅／地域／会場検索、月間カレンダー、駅詳細、試合詳細、お気に入り。
- 時刻未定、延期、中止、日程変更、会場変更、会場未定の表示。
- 日本時間で処理し、デモ基準日を2026-11-07に固定。年月が過ぎても試せる。
- 実在の駅・会場名は場所の説明に使用。チーム・大会・対戦・開催日時・注意時間帯はすべてデモ。

## 仕様の優先順位

ユーザーの追加指示 ＞ 本文の確定仕様 ＞ 型・JSONの契約 ＞ 見た目の参考。
不一致を見つけたら整合を取って変更理由を残す。実データのように見える架空情報、予測精度の数値、実測を装う表示を追加しない。
